# Flutter Mobile Application (`development/mobile/`)

> **Agent Owner**: `thor`  
> **Status**: Optional component of Avengerse.

---

## Overview
This directory is reserved for the cross-platform Flutter mobile application.

- If your project does **NOT** require a mobile app, this directory remains clean and dormant.
- If your project **DOES** require a mobile app, Thor will initialize the Flutter project here, configured with Riverpod/BLoC, GoRouter, Dio API client, and secure token storage matching `docs/08-api-contract.md`.

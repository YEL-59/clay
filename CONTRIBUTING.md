# Contributing to Avengerse (Avengers Protocol)

Thank you for your interest in contributing to the **Avengerse** Multi-Agent Full-Stack Template!

## 1. Golden Rules
1. **Preserve Context Isolation**: Never cross agent boundaries unnecessarily. Keep tokens minimal.
2. **Contract-First**: Updates to APIs must be documented in `docs/08-api-contract.md` before implementation.
3. **Thanos Verification**: Every change must have passing tests.
4. **Validation Scripts**: Always run `./scripts/validate-project.sh` and ensure 0 failures before committing.

## 2. Agent Responsibilities
- Modifying design system? Consult `jarvis.toml`.
- Frontend updates? Consult `friday.toml`.
- Backend/DB updates? Consult `edith.toml`.
- Mobile updates? Consult `thor.toml`.
- QA/Testing updates? Consult `thanos.toml`.
- DevOps/Docker/CI-CD? Consult `ultron.toml`.
- Orchestration & planning? Consult `iron_man.toml`.
